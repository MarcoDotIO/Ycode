# Per-symbol failure conventions for generated unimplemented stubs
# (host-libraries.md section 4). gen_stubs.py derives a default from each
# row's category (and, for syscalls and Mach traps, from the return types
# in specs/simulator/data/{bsd-syscalls,mach-traps}.json). This file
# overrides the default where a name's C return type does not fit it.
#
# Conventions:
#   errno     trap, errno = ENOSYS (78), return -1         (BSD-style)
#   kern      trap, return KERN_NOT_SUPPORTED (46)          (Mach routines)
#   zero      trap, return 0 / NULL / MACH_PORT_NULL / false (pointer, port, value)
#   void      trap, return
#   errret    trap, return ENOSYS (78) as the result        (pthread_*, posix_spawn*)
#   noreturn  trap, then brk #0x7963 (never returns)
#   nop       no trap, return; every register preserved   (stack probes)
#
# Format: <library> <mach-o name> <convention>
