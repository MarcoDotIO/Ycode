# initial value of the generated variable.

# Format:  <library> <mach-o name> <min-bytes> [<init>]
#   <init> is one of  u32=<n>  u64=<n>  bytes=<hex>,<hex>,...  str=<text to end of line>
#   Everything not initialized is zero.
#
# The generator (gen_stubs.py) reserves max(<min-bytes>, the surface JSON's
# sizeUpperBound) bytes so that a client reading up to the host size never
# runs into the next symbol. verify.py requires at least <min-bytes> before
# the next symbol, whether the variable is generated or written by hand.
# Rows for surface data symbols not listed here default to the JSON bound.
#
