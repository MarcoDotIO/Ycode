How to read: **fit[p]** = size the view returns when proposed `p` (`nil` = unspecified dimension,
`∞` = infinity). **placed** = proposal used to place the view in the test container
(default 300×500). **frames** = frames of probed descendants in the container's coordinate
space after placement (x, y, width, height). **dims** = alignment guides of the placed view.

Text-dependent values (anything containing `Text`, `Label`, `Button`, symbols) depend on the
font's metrics and are exact only with the same font; an open implementation with another font
checks them as *relations* (see `10-plan.md` §3). Shape, colour, spacer, frame, padding, stack
and grid arithmetic around fixed-size children are font-independent and must match exactly.

Rows for UIKit-backed containers (`list.*`, `form.*`, `navigationStack*`, `tabView`) are
informative only: their content is hosted in separate UIKit views, and descendant frames in the
container's coordinate space are not reliable (use the global frames in `06-app-and-components.md`).
